### ⚡ Selected Work

* **[AD-BSA (Adaptive Differential Boogeyman Search Algorithm)](https://github.com/Pipin333/AD-BSA)**  
  Continuous global optimization metaheuristic introducing explicit negative learning (*anti-attractors*) and bounded $|\csc(\cdot)|$ repulsion barriers.  
  * Tied at **2.30 Friedman rank with CMA-ES** across the official **IEEE CEC 2020 50D** benchmark suite.  
  * Features dynamic $k$-means anti-attractor clustering with thermodynamic annealing to escape multimodal local traps.

* **[WhatsArr](https://github.com/Pipin333/whatsarr)**  
  Event-driven WhatsApp request gateway built with Baileys for **Radarr, Sonarr, Prowlarr, qBittorrent & Plex**.  
  * Implements fuzzy title matching (`fuzzball` + TMDB), interactive audio selection (Latino, Castellano, Sub), and strict disk quota rules (10 GB max / movie).

* **[Toodles](https://github.com/Pipin333/Tooodles)**  
  High-throughput, low-latency Discord audio streaming engine deployed on Oracle Cloud ARM64 architecture.  
  * Features a hybrid recommender using 256-dimensional ALS latent factor decomposition and Item2Vec embeddings.

* **[jd-watch-controller](https://github.com/Pipin333/jd-watch-controller)**  
  Open-source motion scoring controller for Wear OS & Android written in Kotlin. Streams live accelerometer and gyroscope telemetry with real-time haptic feedback to emulate Just Dance controls.

* **[CalculadoraCopete](https://github.com/Pipin333/calculadoracopete)**  
  Beverage logistics calculator designed for Chilean social gatherings. Practical, zero-friction, and solves an actual weekend problem.
